- 사이트: https://ttokjaetv.github.io/nps-calc/
- 조기 5년 ~ 연기 5년, 11가지 받는 시기 비교 + 정상 수급 대비 손익분기 나이
- 계산 상세: A값·B값·가입월수·가입 시기별 비례상수(가중평균)·기본연금액·부양가족연금·상한(B값)·조정률
- 나이별 누적 수령액 차트·표, CSV·엑셀 내려받기
- 생활비 연결: 필요 생활비 중 국민연금이 채우는 비율 → 나머지를 은퇴 역산 계산기로 넘김, 연 연금이 크면 건보료 피부양자 확인 링크
- 추납(추후납부) 손익: 추납보험료(신청월 기준소득월액 × 납부기한 달 보험료율 × 개월 — 이번 달 신청·다음 달 말일 납부 가정, 2026년 9.5%·12월 신청은 다음 해 요율, 최대 119개월, 임의가입자 A값 상한) vs 늘어나는 월 연금 → 회수 기간·손익분기 나이, 10년 미달자의 수급권 확보 여부
- 공단 조회 금액에 맞추기: 공단 '예상연금액 조회' 월액을 넣으면 평균 소득(B값) 역산

## 계산 기준 (2026-10-13 확인, 출처: 국민연금공단 예상연금 간단계산)
- 월 연금 = 비례상수 × (A + B) × (1 + 0.05n/12) × 지급률 ÷ 12 → 가입기간 부분은 정확히 `가입월수 ÷ 240`
- A값 3,193,511원(2026년 적용), 기준소득월액 하한 41만원·상한 659만원(2026-07~2027-06)
- 비례상수: 1988~1998 2.4 · 1999~2007 1.8 · 2008 1.5 · 2009~2025 매년 −0.015 · 2026~ 1.29(소득대체율 43%)
- 조기 연 −6%(최대 5년), 연기 연 +7.2%(최대 5년), 부양가족연금(배우자 월 25,550원·자녀/부모 월 17,030원)은 조정 제외
- 상한(국민연금법 제53조): 기본연금액 × 조기·연기 조정률(10원 미만 버림) + 부양가족연금 → 그 총액(월별 지급액)이 B값을 넘지 못함. 법은 max(최종 5년 평균, 전 기간 평균 B)이지만 평균 소득 하나만 넣으므로 B값으로 근사. 연기가산분 상한 적용은 공단 실무 확인 필요
- 매년 1월 A값·7월 상하한액이 바뀌면 `src/engine.js`의 `NPS` 값을 고치고 공단 예상월액표로 `nps_table.json`을 다시 만든다

## 파일
- `index.html` — 배포본 (빌드 결과)
- `src/engine.js` — 계산 엔진, `src/template.html` — 화면, `src/build.py` — 둘을 합쳐 index.html 생성
- `src/test.js` + `src/nps_table.json` — 공단 '노령연금 예상월액표'(620구간 × 10~40년, 4,340칸) 원 단위 대조

```
python src/build.py
node src/test.js     # 공단 예상월액표 대조: 4340칸 중 불일치 0칸
```

## 주소로 값 넘기기
금액은 만원 단위입니다.

```
?by=1972&sy=1998&ey=2031&gap=0&b=300&t=0&sp=0&dep=0&plan=90&inf=2.5&need=298&cm=36&cb=300&cv=0
```

- `cm`·`cb`·`cv`: 추납 개월·추납 신청월 기준소득월액(만원)·임의가입자 여부
- `t`: 받는 시기 −5(조기 5년) ~ 5(연기 5년), `sp=1`: 배우자, `dep`: 자녀·부모 수, `inf=0`: 미래 금액 표시 끔
- 보내는 곳: 은퇴 역산 계산기 `?target-monthly=<나머지 생활비>&current-age=<나이>`, 금융소득종합과세·건보료 계산기 `?t=dep&dp=<연 연금 만원>`
