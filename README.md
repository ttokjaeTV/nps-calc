# 국민연금 계산기 · 똑재TV

출생연도·가입 기간·평균 소득으로 **국민연금 노령연금 예상 월액**을 공단 공식 산식으로 계산하는 단독 HTML 계산기입니다.

- 사이트: https://ttokjaetv.github.io/nps-calc/
- 조기 5년 ~ 연기 5년, 11가지 받는 시기 비교 + 정상 수급 대비 손익분기 나이
- 계산 상세: A값·B값·가입월수·가입 시기별 비례상수(가중평균)·기본연금액·부양가족연금·상한(B값)·조정률
- 나이별 누적 수령액 차트·표, CSV·엑셀 내려받기
- 생활비 연결: 필요 생활비 중 국민연금이 채우는 비율 → 나머지를 은퇴 역산 계산기로 넘김, 연 연금이 크면 건보료 피부양자 확인 링크
- 추납(추후납부) 손익: 추납보험료(신청월 기준소득월액 × 납부기한 달 보험료율 × 개월 — 이번 달 신청·다음 달 말일 납부 가정, 2026년 9.5%·12월 신청은 다음 해 요율, 최대 119개월, 임의가입자 A값 상한) vs 늘어나는 월 연금 → 회수 기간·손익분기 나이, 10년 미달자의 수급권 확보 여부
- 추납 3자 비교(2026-11-18): 추납 포기 vs 추납 후 조기수령 vs 추납 후 정상수령을 한 화면에서 비교 — 월 연금·수급 시작·추납 비용·나이별 순누적(비용 차감) 표·차트·손익분기 나이, 상계월수, 단순 회수 기간. 새 엔진 없이 기존 추납·조기/연기·손익분기 엔진 재사용(아래 「추납 3자 비교」)
- 공단 조회 금액에 맞추기: 공단 '예상연금액 조회' 월액을 넣으면 평균 소득(B값) 역산
- 공단 조회 방법 안내(캡처 4장, `img/nps-step1~4.jpg`, 2026-10-13 화면)와 공단 조회와의 차이 비교표
- 추납 신청 화면 안내(2026-11-19 화면, 개인정보 가림 캡처 2장 `img/nps-step5~6.jpg`): 추납액은 공단 신청 화면 4단계(가입내역·추납 희망기간 조회)에서, 늘어나는 월 연금은 이 계산기에서 확인. 공단은 늘어나는 월 연금을 보여 주지 않음

## 계산 기준 (2026-10-13 확인, 출처: 국민연금공단 예상연금 간단계산)
- 월 연금 = 비례상수 × (A + B) × (1 + 0.05n/12) × 지급률 ÷ 12 → 가입기간 부분은 정확히 `가입월수 ÷ 240`
- A값 3,193,511원(2026년 적용), 기준소득월액 하한 41만원·상한 659만원(2026-07~2027-06)
- 비례상수: 1988~1998 2.4 · 1999~2007 1.8 · 2008 1.5 · 2009~2025 매년 −0.015 · 2026~ 1.29(소득대체율 43%)
- 조기 연 −6%(최대 5년), 연기 연 +7.2%(최대 5년), 부양가족연금(배우자 월 25,550원·자녀/부모 월 17,030원)은 조정 제외
- 상한(국민연금법 제53조): 기본연금액 × 조기·연기 조정률(10원 미만 버림) + 부양가족연금 → 그 총액(월별 지급액)이 B값을 넘지 못함. 법은 max(최종 5년 평균, 전 기간 평균 B)이지만 평균 소득 하나만 넣으므로 B값으로 근사. 연기가산분 상한 적용은 공단 실무 확인 필요
- 매년 1월 A값·7월 상하한액이 바뀌면 `src/engine.js`의 `NPS` 값을 고치고 공단 예상월액표로 `nps_table.json`을 다시 만든다

## 추납 3자 비교 (src/engine.js `npsCompare3`·`npsChunap3`)
- 시나리오: A 추납 포기(정상 수급·비용 0) / B 추납 후 조기수령 / C 추납 후 정상수령. 입력 방식 두 가지 — ① 자동(추납 개월·기준소득월액으로 엔진이 추납액과 월 증가분 계산) ② 직접 입력(추납 전 월 연금·늘어나는 월 연금·추납액, 만원 단위, 정상 수급 나이는 출생연도로)
- B의 조기 개월: 추납 후 조기 감액(월 0.5%, 최대 60개월) 월액이 추납 전 월액 **이상**인 가장 긴 정수 개월(내림). 소수 개월(예: 33.3)은 화면에 함께 보이고 정수로 내림해 월액을 추납 전 이상으로 지킨다. 올림하면 추납 전보다 줄어든다
- 순누적(나이 x) = −추납액 + 12 × 월 연금 × max(0, x − 수급 시작 나이). 추납액은 시작 때 한 번에 낸 것으로 보고 할인하지 않으며, 월 연금은 매년 물가만큼 오른다고 보고 오늘 돈 가치로 일정하게 셈(할인율은 반영하지 않음). 손익분기 나이는 연속 나이(만 x세가 되는 순간) 기준이고 `npsBreakEven`과 같은 방식
- 상계월수 = 추납액 ÷ 월 증가분(개월). 단순 회수 기간(C 기준)과 같은 값을 단위만 바꿔 보여 준다
- 주의 문구: 조기노령연금은 가입 10년 이상·A값(NPS.A, 월 약 319만원) 초과 소득이 없어야 받을 수 있고 받는 중 그 소득이 생기면 그 기간 지급이 멈출 수 있음(기준은 공단 확인, 비교에는 미반영), 조기 감액은 평생 고정, 월 연금은 매년 물가만큼 오른다고 보고 오늘 돈 가치로 일정하게 셈(할인율 미반영)
- 주소 매개변수: `m3=1`(직접 입력), `a3`·`d3`·`k3`(추납 전 월 연금·월 증가분·추납액, 만원)
- 글 사례 재현(월 100만 → 120만, 추납 1,100만, 33개월 조기 — `src/test.js`에서 assert):

| 항목 | 글 | 계산기(엔진 정밀값) | 월 100만 평탄으로 본 경우 |
|---|---|---|---|
| B 월 연금 | 100.2만 | 100.2만 (120 × (1−33×0.005)) | 100만 |
| 조기 개월 | 33 | 33 (33.3 내림) | 33 |
| 상계월수 | - | 55개월 (4.58년, 만 69.58세) | 55개월 |
| A↔B 65세 순이익 | 2,200만 | 2,206.6만 | 2,200만 |
| B↔C 손익분기 | 165개월 (78.75세) | 167개월 (78.92세) | 165개월 (78.75세) |

- 글의 100.2만과 165개월·2,200만은 서로 맞지 않는다(165개월·2,200만은 B를 정확히 100만으로 본 값). 계산기는 100.2만 기준 엔진값을 보이고, 테스트는 두 경우를 모두 확인한다(100만 평탄은 `payAt` 대체 함수로 재현)

## 파일
- `index.html` — 배포본 (빌드 결과)
- `src/engine.js` — 계산 엔진, `src/template.html` — 화면, `src/build.py` — 둘을 합쳐 index.html 생성
- `src/test.js` + `src/nps_table.json` — 공단 '노령연금 예상월액표'(620구간 × 10~40년, 4,340칸) 원 단위 대조

```
python src/build.py
node src/test.js     # 공단 예상월액표 대조: 4340칸 중 불일치 0칸
```

## 주소로 값 넘기기
금액은 만원 단위입니다.

```
?by=1972&sy=1998&ey=2031&gap=0&b=300&t=0&sp=0&dep=0&plan=90&inf=2.5&need=298&cm=36&cb=300&cv=0
```

- `m3`·`a3`·`d3`·`k3`: 추납 3자 비교의 직접 입력 방식과 값(만원)
- `cm`·`cb`·`cv`: 추납 개월·추납 신청월 기준소득월액(만원)·임의가입자 여부
- `t`: 받는 시기 −5(조기 5년) ~ 5(연기 5년), `sp=1`: 배우자, `dep`: 자녀·부모 수, `inf=0`: 미래 금액 표시 끔
- 보내는 곳: 은퇴 역산 계산기 `?target-monthly=<나머지 생활비>&current-age=<나이>`, 금융소득종합과세·건보료 계산기 `?t=dep&dp=<연 연금 만원>`
